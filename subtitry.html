Как достать звук из ролика

Один раз создайте команду в приложении «Быстрые команды» (оно уже есть на iPhone):

  1. «Быстрые команды» → + → назовите «Звук из видео».
  2. Добавить действие Кодировать медиа, нажать на стрелку, включить Только аудио, формат M4A.
  3. Добавить действие Сохранить файл.
  4. Нажать на ⓘ внизу и включить Показывать в меню «Поделиться». Тип входа — «Медиа».

Дальше: экспорт ролика из CapCut (любое качество) → в «Фото» открыть ролик → «Поделиться» → «Звук из видео» → выбрать папку. Можно и не делать: приложение примет и само видео, отделит звук и отправит в Gemini только его.

Как получить ключ Gemini (бесплатно)

  1. Откройте aistudio.google.com/apikey и войдите своим аккаунтом Google.
  2. Согласитесь с условиями, если спросит.
  3. Нажмите Create API key (создать ключ).
  4. Скопируйте ключ — он начинается с AIza — и вставьте во вкладке «Настройки».

Ключ хранится только на этом телефоне. Бесплатного лимита хватает на десятки роликов в день.

Как загрузить в CapCut

  1. Откройте проект с готовым монтажом, ползунок — в начало.
  2. Текст → Импорт субтитров → выберите файл .lrc.
  3. Для двух языков импортируйте оба файла: KZ и RU. Каждый станет своей дорожкой — покрасьте и расположите отдельно.
  4. Выберите шрифт и стиль, отметьте «Применить ко всем основным субтитрам».

Важно: после того как отделили звук, монтаж не меняйте — иначе субтитры сдвинутся.
